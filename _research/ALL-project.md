## Overview

Traditional autonomous underwater vehicles, though commonly used in underwater exploration and maintenence, struggle to navigate complex, dynamic environments. Undulatory vehicles which mimic the locomotion of fish are being developed as an alternative for these applications, however to properly control undulatory motion, such vehicles need to be able to sense the flow of fluid around them. This project focuses on fulfilling that need using kinematic sensors to mimic the function of fishes' lateral line, a system of sensory organs that provide them with input about their surroundings. This will be done by attaching pressure sensors and flex sensors to a model of a fish and testing this system in a water tunnel at varying angles. 

## Methods

A trout-inspired rig was designed using SolidWorks, and sensor placement was determined using a combination of computational fluid dynamics simulations and biological lateral line layout. The rig was tested in a water tunnel in static position at varying angles and flow rates in order to develop a machine learning model to interpret kinematic sensor data. This machine learning model was then used to evaluate flow around the body in dynamic motion similar to that of an undulatory swimmer.
